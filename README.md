### 🚀 Sobre mí

Me apasiona construir **mecánicas y sistemas de videojuegos**, **herramientas de optimización y add-ons para artistas 3D** en Blender, y **aplicaciones móviles y soluciones web escalables**.

- 🎯 **Enfoque principal:** Integración de arte y programación (Technical Art, Shaders, Pipelines 3D/2D).
- 🕹️ **Game Development:** Desarrollo con Godot Engine y Unity, prototipado de mecánicas y game feel.
- 💡 **Open Source & Herramientas:** Creando add-ons para agilizar el flujo de trabajo de creativos digitales.
